# Changelog

## 0.1.1 — Documentation and package information

- Expanded npm README with installation, framework examples, utilities, themes, recipes, CLI/API usage, troubleshooting, and compatibility limits.
- Added GitHub repository, homepage, issue tracker, and author metadata.
- Included contribution, security, and release guides in the npm archive.
- Verified documentation examples and independent package installation.

## 0.1.0 — First alpha

- Publishable `@suryanshp1/zencss` distribution with ESM, CommonJS, TypeScript declarations, JavaScript source maps, CSS, and an executable CLI.
- Framework-independent, deterministic utility compiler and source extractor.
- Four semantic themes: Washi, Sumi, Matcha, and Mono.
- Button, Card, Input, and Badge CSS recipes with selected size/tone/density modifiers.
- CSS-first theme, custom utility, and recipe directives.
- Responsive, state, dark, reduced-motion, and container variants.
- Vite plugin with per-file candidate caching and stylesheet updates.
- CLI build/watch/explain commands and advisory lint/migration reports.
- Curated prebuilt stylesheet with 212 classes.
- Playground and documentation app, runnable React starter, and vanilla HTML example.
- npm consumer guide, contribution guidance, security policy, and release instructions.

The alpha does not promise complete Tailwind compatibility, compiler CSS source maps, editor IntelliSense, comprehensive ZenLint checks, or certified cross-browser/accessibility coverage. See the README for supported syntax and current limitations.
